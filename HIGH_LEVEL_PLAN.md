### 1.2 Story Arcs Identified

#### Arc A: The Freedom Quest (Primary Opening)
- Player is summoned to the mansion of **Richel Decos**, viceroy of New Attnam/Tweraif
- Given a letter to deliver to **Petrus** in Attnam
- Must travel through underwater tunnel, reach Attnam Cathedral
- Petrus tasks player with slaying **Elpuri** (evil dark frog) who hates Valpurus
- Player brings Elpuri's head → granted freedom
- Later: Tweraif freed from Decos; player becomes new viceroy

#### Arc B: The Xinroch Tomb Quest
- Delve into the **Tomb of Xinroch** (11 levels, necromancy-heavy)
- Guarded by fanatical Dark Knights who followed Xinroch in death
- Kamikaze dwarves in gas chambers on deeper levels
- Contains artifacts from the Divine War: Neerc Se-ulb, Mjolak, Vermis, Turox

#### Arc C: The Aslona Civil War
- Kingdom of **Aslona** with a civil war between rebels and crown forces
- Crown Prince **Artorius** is missing (allegedly goblin raid)
- Player can side with either rebels or crown
- Involves **Goblin Fort**, **Pyramid**, **Rebel Camp**

#### Arc D: Side Quests & Locations
- **Sumo Wrestling** — Huang Ming Pong, arena fights in New Attnam
- **Black Market** — hidden shop in leafy forest
- **Fungal Cave** — journal mentions strange fungal growths near coal cave
- **Dark Forest / Irinox** — mysterious dungeon pair
- **Mondred** — empty area/tundra location

### 2.2 Script File Formats
All `.dat` files use a C-like preprocessor syntax with `#define`, `Include "path"`, and custom DSL for game objects:
- `item { ... }` — item definitions
- `material { Config NAME; { ... } }` — material definitions  
- `character { ... }` — monster/NPC definitions
- `Dungeon NAME; { ... }` — dungeon definitions with room layouts, OTerrainMaps

## 4. Technical Automation Plan (To Be Detailed in EXECUTION_PLAN.md)

### 4.1 Image Generation Pipeline
- **Model**: `wikeeyang/Flux2-Klein-9B-True-V2` via HuggingFace Diffusers library
- **Purpose**: Generate all new sprite sheets, terrain tiles, menu art, character portraits
- **Approach**: 
  - Catalog each existing asset with its dimensions and purpose
  - Write prompts describing the new fantasy setting equivalent
  - Batch generate images at required resolutions
  - Maintain pixel-art aesthetic consistent with roguelike genre

### 4.2 Text Generation Pipeline  
- **Model**: qwen3.6-35b-a3b via pi.dev API
- **Purpose**: Generate all new creative text content
- **Approach**:
  - Rewrite all `.dat` script files (item names, material names, character descriptions)
  - Generate new lore documents in the same style as existing ones
  - Update hardcoded C++ dialogue strings
  - Maintain game balance by keeping numerical values unchanged

### 4.3 Script File Transformation Strategy
The `.dat` files are the primary creative content and can be transformed programmatically:
1. Parse each `.dat` file to extract string fields (names, descriptions)
2. Map old names → new names via a translation table
3. Use LLM to generate contextual replacements for descriptive text
4. Validate that numerical values (stats, prices, etc.) remain unchanged

### 4.4 C++ Code Changes Required
Files requiring story-specific string updates:
- `human.cpp` — quest dialogues (~100+ references)
- `game.cpp` — opening text, story messages (~50+ references)
- `gods.cpp` — prayer effect messages
- `gear.cpp` — artifact hit effect messages
- `rooms.cpp` — room-specific dialogue
- `char.cpp` — death messages referencing story states
